## Findings

### QA-240: Light-theme last-refresh text falls below accessible contrast

- Severity: warning
- Related task / requirement: task 5.1; accessible Live / Updates paused status presentation in both themes
- Location: `dashboard/src/styles.css:38,1417`; last-refresh label markup is `dashboard/src/app.html:162`
- Expected / actual: Normal-sized status text should retain at least 4.5:1 contrast. At the first light-theme viewport (1440px), the Live state label measured 4.83:1 but the last-refresh text measured 4.37:1. The light-theme values are `--muted: #657987` over `--surface-subtle: #fafbfd`.
- Reproduction: Run the isolated compiled Release fixture, connect, switch to light theme, and inspect `.live-status-refresh` and `.live-status` computed colors at 1440px. The actual review run is recorded in [results.json](../../../../artifacts/realtime-dashboard-updates/reviews/qa-011/run-2c0398fc-ae86-4ac4-b383-d2dbbb9802e8/results.json).
- Evidence: The browser run failed the contrast assertion with ratios 4.83:1 and 4.37:1. Dark theme passed at all three assigned widths. No light-theme screenshot was captured because the driver stopped at the first light case.
- Recommended correction: Darken the light-theme muted status-text color enough to exceed 4.5:1 on the status surface, then rerun all light widths and preserve their screenshots.
- Relationship: New finding in reserved QA-240–259 range.
