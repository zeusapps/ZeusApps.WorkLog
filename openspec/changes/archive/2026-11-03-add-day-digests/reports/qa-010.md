## Findings

### QA-141: First packaged e2e run had one failure that did not reproduce

- Severity: warning
- Related task / requirement: task 5.5, acceptance "all dashboard tests pass"
- Location: `dashboard/e2e/dashboard.spec.ts:1390` ("Daily view > copies the plain-text block, and the Markdown format with links is remembered")
- Expected / actual: expected a pass. The first packaged run failed this test, which caused the 6 later serial tests not to run. An identical second run passed 40 of 40. The unrelated Daily test touches the system clipboard, which is a plausible source of flakiness. The first-run error context was overwritten by the second run, so the cause is unconfirmed.
- Reproduction: `npm run test:e2e --prefix dashboard` with the packaged exe, repeated.
- Evidence: run 1 summary "1 failed, 6 did not run, 33 passed"; run 2 "40 passed". The failure is outside the footer CSS (clipboard/Daily area) and the fix cannot plausibly affect it.
- Recommended correction: orchestrator to rerun once more to judge flakiness, and have the developer harden the clipboard read if it recurs.
- Relationship: none

### QA-142: Change-card top padding also changed from 20px to 14px

- Severity: suggestion
- Related task / requirement: task 5.5 ("keep layout apart from the horizontal padding")
- Location: `dashboard/src/styles.css:758-760` (`.board-card.change-card { padding: 14px 16px 0; }`)
- Expected / actual: expected only horizontal padding to change. Actual: the shorthand also reduces top padding from 20px to 14px, so change cards are 6 px shorter and their header content sits 6 px higher.
- Reproduction: inject `.board-card.change-card{padding:20px 23px 0 !important}` in the packaged dashboard fixture and compare card heights (232.5 vs 226.5 for "Board started").
- Evidence: measurements in the checks table. The result matches the ticket and ad-hoc cards' 14px top, so it is plausibly intended and visually consistent in [the screenshot](../screenshots/qa-010-board-footers.png).
- Recommended correction: either state the 6 px top change as intended, or write `padding-left`/`padding-right: 16px` only. No test covers vertical padding.
- Relationship: none
