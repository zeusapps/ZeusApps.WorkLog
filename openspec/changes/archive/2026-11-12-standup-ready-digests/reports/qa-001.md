## Findings

### QA-001: Blockers section says "No blockers recorded" while Today is still loading

- Severity: suggestion
- Related task / requirement: 4.1; daily-preparation "Today and blockers" (Today loading state)
- Location: `dashboard/src/app.html` Blockers section (`@if(dailyBlockerGroups();as groups)`), `dashboard/src/app.ts` `dailyBlockerGroups`
- Expected / actual: while the board inputs load, Today shows "Reading today's work" and Copy is unavailable; the Blockers section should not make a claim yet. `dailyBlockers(this.dailyTodayView()?.items ?? [], ...)` returns an empty array when Today is not loaded, which is truthy, so the page shows "No blockers recorded".
- Reproduction: open Daily with the board input delayed (source reading; not executed in a browser).
- Evidence: source inspection only.
- Recommended correction: show a loading state, or omit the statement, until `dailyTodayView()` is non-null; add a unit test.
- Relationship: none
