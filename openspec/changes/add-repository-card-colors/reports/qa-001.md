## Findings

### QA-001: Narrow viewport acceptance counts the synthetic palette grid

- Severity: warning (blocks task 3.1 acceptance until corrected and rerun)
- Related task / requirement: 3.1; Repository-colored Ongoing board footers, narrow viewport acceptance requiring no horizontal overflow or clipped footer content.
- Location: at the reviewed identity above, `dashboard/e2e/dashboard.spec.ts:118` and `dashboard/e2e/dashboard.spec.ts:1402-1411`.
- Expected / actual: the 390px check should measure the real Ongoing board without horizontal overflow. The test appends a synthetic `.repository-palette-evidence` section containing ten cloned cards and leaves it attached when it changes the viewport to 390px. Its inline media rule makes that grid two columns below 760px, while the actual `.board` collapses to one column at widths below 1000px. The assertion uses the whole document's `scrollWidth`, so the narrow synthetic evidence grid can cause `overflow` to be true independently of the real board. The coordinated run observed `overflow === true`; it therefore does not establish whether the actual board itself overflows at narrow width. The clipped-footer count is not asserted because the overflow assertion fails first.
- Reproduction: run the browser command in the task 3.1 row on a free `WORKLOG_DASHBOARD_TEST_PORT` with `WORKLOG_REPOSITORY_COLOR_EVIDENCE_PREFIX=qa-001`. The repository-color test passes its light/dark contrast, neutral-background, identity, and column-movement assertions, then fails at the 390px document overflow assertion.
- Evidence: coordinated root run, 8 selected tests with 3 passed and the repository-color test failed; [dark screenshot](../screenshots/qa-001-dark.png) and [light screenshot](../screenshots/qa-001-light.png) show the rendered palette and neutral cases at desktop width. This finding is about the narrow measurement's test fixture contamination; no product overflow is asserted from the available run.
- Recommended correction: remove the synthetic palette evidence section before setting the narrow viewport and measuring the real board, or otherwise keep the palette fixture from contributing to document width. Then rerun the narrow board overflow and clipped-footer assertions and save the narrow screenshot.
- Relationship: new QA finding; no earlier QA finding IDs assigned.
