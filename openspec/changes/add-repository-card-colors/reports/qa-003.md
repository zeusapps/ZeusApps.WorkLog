- Severity: warning

- Expected / actual: the repository-color browser test should verify a real column movement in every supported dashboard acceptance mode. It changes a task checkbox and expects Board proposal to move from Proposed to In progress. The dashboard process used the Release DLL with Node/OpenSpec removed from its runtime PATH; no packaged executable was used. `.github/workflows/validate.yml` uses `WORKLOG_DASHBOARD_NO_NODE=true` with the packaged dashboard browser acceptance command.
- Evidence: coordinated runtime failure plus source inspection of the test, existing `changeStage` fallback, and CI setup. The standard normal-mode eight-test run passed, but it does not cover the no-Node mode.
- Recommended correction: keep a genuine stage transition and stable-color assertion in no-Node mode by using a recorded-work observation there (or another isolated mode-compatible fixture), while retaining exact fixture restoration and the later four-card expectations. Do not weaken the product's no-Node stage fallback or later test assertions.
