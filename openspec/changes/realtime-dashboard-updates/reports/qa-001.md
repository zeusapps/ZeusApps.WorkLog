## Findings

### QA-001 — warning: baseline harness has no deterministic fault controls

- Location: `scripts/c06-dashboard-acceptance.mjs:21-53`, `scripts/c06-dashboard-acceptance.mjs:107-110`
- Expected: task 1.1 calls for an isolated harness with deterministic faults and verifiable bounded cleanup.
- Actual: the harness accepts `--setupSmoke`, `--smoke`, or `--run`; its execution path exercises healthy packaged startup, visibility, and writers, but defines no fault mode or deterministic mechanism to trigger a failure and verify recovery/cleanup.
- Reproduction: source inspection of the accepted mode gate and the single packaged-server start path; no fault option, fault schedule, or injected failure is present.
- Evidence: task 1.1 in `tasks.md`; current harness lines above. The successful short smoke demonstrates normal-path visibility and cleanup only.
- Recommendation: add a deterministic harness fault case for the specific 1.1 cleanup/control requirement, or reconcile that wording with the later fault-matrix task and record where its required evidence will be produced. Keep this separate from product correctness claims.
