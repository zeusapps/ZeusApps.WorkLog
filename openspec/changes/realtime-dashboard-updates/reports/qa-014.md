## Findings

### QA-300: Archive convergence fixture requires an unrelated Catalog revision

- Severity: warning.
- Related task / requirement: ORCH-003 archive move and opened-document convergence.
- Location: `tests/WorkLog.Tests/Dashboard/DashboardLiveCoordinatorTests.cs:351` at reviewed source identity `0d77685`.
- Expected / actual: The archive regression should gate on the document state required by the scenario: the opened change resolves as archived, its content is available, the document revision catches up, and reconciliation becomes clean. The fixture additionally requires the Catalog counter to advance before it runs those checks. Production `CatalogProjectionStamp` (line 629) covers repositories, sources, launch repository, notices, and source notices, but not `snapshot.Changes`; the catalog counter is therefore not required to advance for an archive-only metadata change. The test can time out while the relevant Documents revision has advanced, leaving the intended archived-document assertions unreachable.
- Reproduction: Developer-reported current run of `RecursiveFilesystemWatchAllowsExternalArchiveMoveAndRefreshesOpenDocument`: the directory move succeeds, then its 10-second wait at the compound Catalog/Documents/Dirty predicate fails. The predicate is at lines 351-353. `CatalogProjectionStamp` and Documents revision behavior are at `src/WorkLog/Dashboard/DashboardLiveCoordinator.cs:461-469,629-636`.
- Evidence: The current source test expects Catalog and Documents both to advance. The catalog projection deliberately omits the change list; `CatalogSnapshot.Revision` separately includes each change’s directory name, archived flag, and documents. This identifies the Catalog clause as an over-constrained test gate; it does not prove whether the opened document converged in the failed run.
- Recommended correction: Preserve the archived metadata and content assertions, but gate on the relevant Documents revision and clean reconciliation instead of requiring a Catalog revision for a change-list-only archive move. Treat actual browser refresh as unverified until the corrected fixture assertions and browser run complete.
- Relationship: Recheck of ORCH-003; no claim of a production convergence defect or verified runtime pass.
