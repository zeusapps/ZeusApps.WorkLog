## Findings

### ANALYSIS-043: Periodic full-check does not invalidate repository identities after a missed lifecycle hint

- Severity: warning.
- Related task / requirement: 2.2–2.4; journal replacement must refresh journal-derived repository identities even if the lifecycle watcher hint is missed.
- Location: `src/WorkLog/Dashboard/DashboardLiveCoordinator.cs:338–345,480–493`; `src/WorkLog/Dashboard/SourceCatalog.cs:48–53,116–128`; at the reviewed identity.
- Expected / actual: A full periodic reconciliation that detects journal file replacement must invalidate/rekey the derived repository identity cache as well as advance the journal revision. Currently `ProcessBatch` calls `catalog.InvalidateJournalRepositories()` only when `batch.JournalLifecycleChanged` is true. Periodic full-check requests journal reconciliation but `ReconcileJournalAsync` only advances `journalRevision`; `SourceCatalog` recomputes names only when the journal's maximum rowid or its explicit invalidation version changes. If the watcher hint was missed and replacement preserves the maximum rowid, repository A can remain cached after the database has been replaced by repository B.
- Reproduction: Seed journal A with one row; build the catalog; atomically replace it with journal B also having one row; omit `FileLifecycleChanged` and wait for the periodic full-check. Compare `/api/catalog` repositories before and after. The existing tests exercise same-rowid A-to-B only with `FileLifecycleChanged: true` (`DashboardLiveCoordinatorTests.cs:396–435`) or directly call `InvalidateJournalRepositories` (`SourceCatalogTests.cs:109–134`), so they do not exercise the missed-hint case.
- Evidence: Source trace shows periodic full-check in `DashboardLiveCoordinator.cs:170–177`, journal marker reconciliation in `:480–493`, explicit-only invalidation in `:338–345`, and cache refresh condition in `SourceCatalog.cs:121–128`. No runtime reproduction was performed.
- Recommended correction: Carry validated journal lifecycle identity into the derived repository-cache refresh condition, or otherwise detect and invalidate on a replacement discovered by periodic marker reconciliation, without rerunning repository queries for every unchanged rowid.
- Relationship: Existing ANALYSIS-043 from `../reports/analysis-003.md`; remains open. No new finding allocated.
